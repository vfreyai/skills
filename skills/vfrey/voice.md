# Voice and script length

Read this when the person gives a length ("20 to 30 seconds"), asks about the voice, or a run says it used the system voice. Back to `SKILL.md`.

## Sizing a script to a length

If they gave a length ("20 to 30 seconds"), pass `--duration 20-30` in step 5 and size the script by the pace in the `series kit` Settings block (Voice and Pace lines; the voice named there, such as "Samantha, the system voice on this Mac", is the one that will speak: time a draft with that voice: for the system voice `say -v Samantha`, never whichever voice `say -v '?'` lists first; for a natural voice write the lines to a text file, one line per beat, and run `npx vfrey voice sample <voice> --file lines.txt --language <code>`, which times them the way the tick does and prints the pace and the film length). The Pace line says where its number comes from: "measured on <voice>" only after that voice read a sample or a film (`voice sample` keeps it, and `series kit` then prints it); otherwise it is an estimate from earlier measurements: about 3.5 words a second for macOS Samantha and for the Supertonic voice in English, about 3.1 for the Supertonic voice in Vietnamese, 2.6 for any other voice (52 to 78 words for 20 to 30 s at 2.6; 70 to 105 at 3.5). Sample your draft before you trust an estimate, and aim at the middle of the range. The film is the voice plus 0.3 s. A voice outside the range stops before the render, the tick exits 1 with the reason on stderr, and the Fix names how many words to cut or add to land in the middle.

## Which voice speaks

Voice is on by default. The natural voice (Kokoro, English) runs on the computer with no key once `npx vfrey voice install` has run (about 92 MB download, about 237 MB on disk, once, offline after); until then the system voice speaks (macOS `say`, Windows SAPI, Linux `espeak-ng` or Piper), which sounds robotic. **For any other language** (Vietnamese, French, Spanish, German, Portuguese, Japanese, Korean, 31 languages, English included; not Chinese) the free natural voice is the multilingual one: `npx vfrey voice install --language vi` (Supertonic 3, about 401 MB download, about 443 MB on disk, once, offline after, model licence OpenRAIL-M: commercial use allowed with use restrictions). With it installed, a script in a language it reads uses it by default (English stays Kokoro). **When a run summary says `Voice: <name>, the system voice. For a natural voice run: npx vfrey voice install ...` (or `... --language vi`), tell the person and offer to run it** (it downloads a public model into `~/.vfrey/models/`; it never runs on its own). Offer the free local voice first, and ElevenLabs (their own key) only after that. `npx vfrey voice list` shows the voices, `npx vfrey voice sample <voice>` writes a short mp3 to listen to, and `npx vfrey desk series update --id <series> --voice kokoro:af_heart` (or `supertonic:F1`, `elevenlabs:<voice id>`, `openai:nova`) sets a series' voice. ElevenLabs (`TTS_PROVIDER=elevenlabs` with `ELEVENLABS_API_KEY`, or the key on the desk Connections page) and OpenAI (`TTS_PROVIDER=openai` with `TTS_API_KEY`) are the person's own paid keys: **never pick or suggest sending script text to a paid voice unless that key is already set**, and never ask for the key in chat. `TTS_PROVIDER=none` is silent. A machine with no voice at all stops with a `Fix:` line. No model key is needed. To check a dashboard link is live: `curl -s -o /dev/null -w "%{http_code}" <url>` expects `200`.
