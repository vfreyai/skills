# Engines

Read this when the person names an engine, an engine is unavailable, or the series engine is "Made by your agent". Back to `SKILL.md`.

The person chooses. `npx vfrey engine list` shows ready or unavailable with reasons; `npx vfrey engine use <id>` sets the machine default (Render until then: it is the default engine, and it draws HTML + GSAP scenes). For a series run the engine is the series' (shown in `series kit`): pass no `--engine`. When the person names a different one for one video, pass `--engine remotion|vfrey-render|hyperframes|pictures|agent` with `--override engine` (without it the run is refused); to change it for good, `desk series update --id <series> --engine <id>`. **When the series engine is Made by your agent (`agent`), you make the whole MP4 yourself and vfrey finishes it: read `agent-video.md` next to this file** (`tick` writes the brief folder `scenes/<idea>/agent/` and waits; read `brief.md`, make the video with your own tools, then `npx vfrey attach <run> <file.mp4> --tool "<what you used>"`; if you cannot make video, say so and offer to switch the engine). With no series, `--engine` works as before. Order: the series engine, the project's `engine` in `vfrey.json`, then the machine default (`--engine` decides only where the series names none). Pictures & clips: see `media.md`. The `Engine:` line says when it came from `vfrey.json`. Otherwise pass none and say which engine rendered (`Engine:` line). Render's first render downloads Chrome Headless Shell (about 170 MB download, about 574 MB on disk). HyperFrames needs the upstream CLI. The only fallback: when nobody chose an engine and Render cannot render here, the run uses Remotion and prints one `!` line saying why and how to make Render ready (relay it). An engine the person or the project chose never falls back: an unavailable or failed one ends the run with a `Fix:` line naming another one. Relay it; never quietly switch. Write scenes as HTML + GSAP (`index.html`) unless the person asks for Remotion; a project or series that recorded `remotion` keeps it.
